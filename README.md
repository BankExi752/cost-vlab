# 智控成本 · 数创价值 —— 制造企业全流程成本管理虚拟仿真决策实训

2026 中国仿真创新应用大赛 · 仿真教学应用赛道 · 虚拟仿真实验设计方向（Streamlit 教学应用 V4.0）

依据《智控成本数创价值_设计方案_V4.0》实现：

- **28 步交互式仿真实验**：模块A 成本核算基本功（10 步）→ 模块B 两法对比与决策（9 步）→ 模块C 作业责任与降本（9 步）；
- **算账闭环四指标**：单位产品成本 / 经营利润 / 成本偏离指数 / 责任绩效分，每步操作后实时刷新；
- **红线机制（3 条 · 两次触发制）**：成本造假 / 虚增存货 / 责任甩锅，第一次警告+扣30分，第二次终止；
- **5 类风险事件**随机触发（含二次确认），原材料涨价/紧急插单/设备故障/批量不合格/客户降价；
- **AI 能力（本地规则引擎降级）**：金点子四维评判（创新30%+可操作30%+成本影响25%+业财融合15%）、每步提分建议；
- **全局易用性**：28 步进度导航、四指标面板、每 5 步里程碑鼓励、3 次悔棋、8 个小白化词条、
  同口径复盘、五维能力雷达（ECharts 风格）、经营决策报告书、教师模式（成绩导出）。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run main_app.py
```

## 部署

- GitHub 仓库 main 分支，Streamlit Cloud 自动部署绑定。
- 依赖仅 streamlit + pandas + plotly，无外部模型依赖；AI 判定由本地规则引擎完成。

## 结构

- `main_app.py`：单文件应用（算账引擎纯函数 + 28 步 UI + 红线/风险/AI + 报告）
- `smoke_test.py`：引擎冒烟测试（标准例题逐位一致 + 7 边界用例 + 红线 + AI）
- `test_apptest.py`：AppTest 端到端（跑通 28 步全流程）
- `requirements.txt`：运行依赖
